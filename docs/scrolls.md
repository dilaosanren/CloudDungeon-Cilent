# 十二种基础卷轴

早期独立演示入口已移除；下述正式系统、资源和接入接口保留。

本页保留基础卷轴移植范围；当前PvP候选见[物品清单](pvp_item_pool.md)，对战规则见[联机说明](pvp_online.md)。

| 卷轴 | 效果和交互 |
| --- | --- |
| 鉴定 | 按用户选择消费一张，仅播放阅读与原版蓝色问号粒子，不打开选物或改变知识状态。 |
| 催眠 | 给视野内角色和自己施加 5 回合困倦，随后魔法睡眠；盟友每回合恢复 1 生命，回满或受击醒来。 |
| 探地 | 阅读后本局持续显示所有地面升级卷轴位置，穿透迷雾，拾取／塌陷后同步移除；仅向使用者提供位置，详见[重做说明](mapping_scroll.md)。 |
| 镜像 | 周围九格的空地随机召唤两个镜像，1 生命，初始隐形，攻击后显形，造成一半伤害向上取整。 |
| 狂怒 | 唤醒并引导全地图角色，视野内非盟友狂乱 5 回合；播放扩张声波和挑战音效。 |
| 充能 | 持续 30 回合，每回合额外积累 0.25 法杖充能，包含最后一回合；原版能量粒子及充能图标。 |
| 祛邪 | 选择有诅咒、诅咒附魔/刻印或穿戴时受到降级影响的物品；解除诅咒及降级。相邻怨灵可直接净化。 |
| 复仇 | 快照视野内角色，伤害随读者失血增强；幸存者失明 10 回合，读者失明 10、虚弱 20 回合；白色闪光和爆破音效。 |
| 传送 | 优先未探索，其次视野外，再其次可见区域；限定可达、非秘密、未占据的地面；解除缠绕。 |
| 恐惧 | 视野内非盟友恐惧 20 回合，以读者为恐惧来源；受击缩短 5 回合。原版五束红色光芒。 |
| 嬗变 | 背包选物，武器/投掷武器变成同阶其他类型，法杖、戒指、饰物、种子、符石换类型；普通药水/卷轴与对应合剂/秘卷互换。 |
| 升级 | 背包选物，再显示原版样式的确认窗口，确认才消费；提升等级并应用诅咒、附魔/刻印、法杖树脂和投掷武器恢复规则。 |

升级后如有剩余卷轴，会继续显示同一物品的升级预览；“返回”或 Esc 返回物品选择，再
关闭背包可停止。全部物品已知，因此取消选物不消费卷轴，也不出现鉴定导致的取消惩罚。
预览保留原版 120 像素内容宽度、当前/升级后图标、像素等级数字和 16 像素按钮，法杖
显示原版伤害/充能对比；不增加力量需求 UI。其他装备的完整战斗属性由正式装备系统提供。

阅读解除隐形、消费一张、使用 `HeroSprite.read` 帧和速度，并在动画结束后结算一回合。
失明、魔法免疫、瘫痪、冻结、睡眠、移动中或物品不可用时均不会消费卷轴。
被诅咒法术书限制通过角色数据接入，祛邪卷轴保留例外。
传送无落点/角色不可移动时，原版会消耗卷轴但不启动阅读动画，也不花费一回合；此行为保留。

## 接入

`ScrollController` 扩展已有 `PotionController`，共享药水、法杖、环境、角色和回合状态。
`ScrollWorld` 包含卷轴规则；`ScrollEffects` 包含原版粒子/画面公式；`ScrollMirrorSprite`
复用未修改的六英雄图集，并采用原版镜像的待机、行走、攻击和死亡帧。

```gdscript
var controller := ScrollController.new()
dungeon.add_child(controller)
controller.bind(dungeon)
controller.world.add_actor(player, player_cell_id)
controller.setup_inventory(player_inventory, player)
controller.inventory_ui = bag_ui
bag_ui.setup(player_inventory)
controller.world.carry(player, player_inventory.all_items())
controller.used.connect(func(_item, _action, cost):
    controller.scroll_world.spend(cost))
# 普通使用也可通过 player_inventory.execute(scroll, "READ")。
```

每个角色/地图使用自己的控制器和背包。宿主不要同时从 `finished` 和 `used` 重复推进
回合；此演示从 `used` 发出背包 `turn_spent`，统一消费时间。
无 UI 的宿主可监听 `selection_requested`，然后调用 `select_target`；有 UI 时自动使用
原版背包选择器和升级窗口。`cancel_selection()` 释放选物状态。

角色占格、门/陷阱发现和传送直接同步已有地图；探地由宿主根据角色感知标记扫描地面升级卷轴，并只向使用者同步位置。地图没有原版 RegularLevel 的
房间元数据，因此传送采用原版 `teleportInNonRegularLevel` 的完整可达性与探索优先规则。
`retreat_step(actor)` 使用移植的 Pathfinder 恐惧退避；`act_demo_enemies` 只是演示宿主
的简易行动，不强制控制 PvP 玩家。镜像通过 `damage_min/damage_max` 接收宿主伤害范围，
正式装备、戒指乘数及职业攻击被动可由宿主提供；没有新增力量/经验 UI。
`world.hooks.on_scroll_used(hero, item, factor)` 可接职业天赋，升级/嬗变系数 2，其余为 1。

嬗变使用从原版 Generator 提取的阶级、权重和普通/特殊对应关系；保留等级、诅咒、
投掷武器组数量、法杖树脂/诅咒灌注与充能，自动更新快捷栏和装备槽，背包满时掉落到地面。
神器提供一次性候选池，用尽后按原版规则改为戒指。特殊物品的外观采用对应符文/瓶色，
全部直接显示真名。此次使用效果覆盖十二种基础卷轴；嬗变产生的秘卷/合剂可以显示和保存，
它们各自的使用效果属于后续特殊物品系统，不用基础卷轴或药水效果代替。

鉴定随机符文、未知物品名字/说明、鉴定进度和鉴定选择流程均不参与运行；保留旧存档
兼容属性，其值恒为已知。十二种卷轴固定分配原版十二种符文贴图，便于 PvP 辨识。

## 美术与来源

沿用原版 `specks.png`、`spell_icons.png`、物品图集和英雄图集，新增七个未改动音效。
音符、扩张声波、发现星光、升级粒子、充能汇聚、祛邪暗影、问号粒子、传送 0.4 秒淡入、
嬗变 0.2/1.4/0.4 秒交叉淡化、五/六束光芒和复仇 1 秒闪光均按源代码实现。
光芒在角色后方，迷雾在游戏世界上方，背包/升级窗口在独立 UI 画布上方。
复仇的全屏闪光作为主动特效覆盖画面，随后自动消失。

`tools/scrolls/import_source.ps1` 复制原版音效，记录 SHA-256 并提取持续时间、嬗变权重、
特殊物品对应关系与投掷武器组数量。

```powershell
./tools/scrolls/import_source.ps1
```
