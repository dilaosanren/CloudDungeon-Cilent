# 背景音乐与独立音量（2026-10-28）

使用工作区用户提供的 `Theme.ogg` 和 `Game.ogg`，原文件保留原样，分别复制到 `assets/audio/theme.ogg`、`assets/audio/game.ogg`。

- 主菜单、设置、日志、对战记录等菜单，以及等待匹配／私人房间等待期间播放 Theme。
- 收到地图预览、选装、战斗或结算状态后播放 Game，返回主菜单切回 Theme。
- 两首音乐从头循环，重复快照或反复打开菜单不会重播当前曲目；只有一个常驻播放器，不叠加多个音乐实例。
- 启动黑屏加载期间异步准备音频，菜单显示时才开始播放。隐藏的对战预热界面不会切歌。独立无界面服务器不创建播放器，也不读取音乐文件。

设置 → 音频增加“音乐音量”滑条，0～10，默认5；0静音。与原音效滑条一样，使用平方音量曲线，修改即时生效并保存至 `user://client_settings.cfg` 的 `music_volume`。旧配置没有此项时使用默认值，重启恢复选择。

`assets/audio/default_bus_layout.tres` 提供 Master → 输出，以及分别发送到 Master 的 SFX／Music 两个子总线。所有原音效入口（含倒计时）已改用 SFX，Master 保持中性；关闭音效或音效调至0不会关闭音乐，音乐调至0也不影响音效。原音效音量、关闭开关及保存值继续有效。
