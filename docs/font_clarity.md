# 英文与数字清晰度修复（2026-10-28）

原共享界面字体把英文和数字先按小字号、固定2倍密度、无抗锯齿栅格化，再跟随菜单／窗口缩放。在小字、非整数缩放或高分辨率设备上，细笔画和字母内部空隙会失真。

`scripts/ui/ui_assets.gd` 现在仍使用原 `pixel_font.ttf`，但共享UI改用96px MSDF图集、32px距离范围，在最终显示尺寸重建字形边缘。各倍率共用同一个字体资源，不再创建不同 oversampling 的字体副本。中文继续使用原捆绑 Droid Sans Fallback；已经按实际屏幕像素绘制的 NativeRichText、战斗飘字原生栅格路径和PNG位图计数保留。

所有界面字号、字体文件、描边设置（4）、窗口和按钮尺寸均未修改。字形布局仍使用相同字号；不同栅格化方式的像素取整使测试长字符串宽度最多相差2个逻辑像素。
