# PvP 选取池物品清单

当前共 **117种**可出现在选取池。

完整价格见 [当前 PvP 物品价格](pvp_item_prices.md)，包含装备+0～+2、药剂／卷轴1～2份及种子／符石1～3份的价格。双方初始各500金币。

升级卷轴已移出选取池；当前源码每局地图开战时生成6张、三对对称位置。所有初始含深渊的地图额外排除冲击波法杖后为116种选购物品，当前包括裂隙／地心／夹层。2026-10-27新增腐蚀酸雾与魔能透视合剂仅更新源码，未重新打包或部署。

按当前服务器候选来源和PvP排除名单整理。每局近战、投掷、护甲、法杖、戒指各随机3项，共15格；剩余21格从药剂（含合剂）、卷轴、种子、符石合并候选池中等概率、不放回抽取。全部36项仍按类别分组，同局不重复类型，不会一次提供全部候选。等级和数量变化不计为新类型。
地图按实际CHASM地形决定是否禁售冲击波法杖，不按名字写死；没有初始深渊的地图保留该法杖。11图及来源见[地图接入记录](curated_maps.md)。

- 浮空药剂（`PotionOfLevitation`）
- 灵视药剂（`PotionOfMindVision`）：持续5t。
- 净化药剂（`PotionOfPurity`）
- 毒气药剂（`PotionOfToxicGas`）
- 麻痹药剂（`PotionOfParalyticGas`）
- 液火药剂（`PotionOfLiquidFlame`）
- 冰霜药剂（`PotionOfFrost`）
- 极速冰冻合剂（`PotionOfSnapFreeze`）：100金币／瓶，1～2瓶；地面冻结5t、水中10t、缠绕5t。
- 精力回复合剂（`PotionOfStamina`，用户所称精力恢复合剂）：60金币／瓶，1～2瓶；20t体力充沛，移动速度提升50%。
- 奥术护盾合剂（`PotionOfShielding`）：60金币／瓶，1～2瓶；普通奥术护盾补至至少20点，保留更高护盾，不叠加，不提供体力充沛。
- 暗夜迷雾合剂（`PotionOfShroudingFog`）：60金币／瓶，1～2瓶；投掷释放扩散迷雾，遮挡双方视野，投掷者也无法透视，不伤害、不阻挡移动或投射物。
- 暴风骤雨合剂（`PotionOfStormClouds`）：40金币／瓶，1～2瓶；扩散雨云、灭火、淹没地形／陷阱，对火属性目标造成原版雨云伤害。
- 火龙吐息合剂（`PotionOfDragonsBreath`）：80金币／瓶，1～2瓶；默认饮用后选方向，6格／60度火锥、8t基础燃烧／5t残废，投掷仅泼洒。
- 大地护甲合剂（`PotionOfEarthenArmor`）：60金币／瓶，1～2瓶；树肤额外固定抵挡8点物理攻击伤害，每3t衰减1点，魔法／持续伤害不抵挡。
- 全面净化合剂（`PotionOfCleansing`）：60金币／瓶，1～2瓶；清除可净化负面状态并保护5t，可饮用或投掷命中角色，保留原版特殊例外，不治疗／清环境／解装备诅咒。
- 腐蚀酸雾合剂（`PotionOfCorrosiveGas`，用户所称酸蚀合剂）：80金币／瓶，1～2瓶；原版225浓度扩散酸雾，PvP起始强度5，腐蚀伤害逐步增长，也影响自己。
- 魔能透视合剂（`PotionOfMagicalSight`）：100金币／瓶，1～2瓶；6格范围穿墙透视10t，解除并免疫致盲，不替代灵视识破隐形。

## 卷轴（8 种）

- 催眠卷轴（`ScrollOfLullaby`）
- 探地卷轴（`ScrollOfMagicMapping`）：40金币／张，本局持续显示所有地面升级卷轴位置，拾取／塌陷后移除标记，见[重做说明](mapping_scroll.md)。
- 镜像卷轴（`ScrollOfMirrorImage`）
- 充能卷轴（`ScrollOfRecharging`）
- 复仇卷轴（`ScrollOfRetribution`）
- 传送卷轴（`ScrollOfTeleportation`）
- 恐惧卷轴（`ScrollOfTerror`）：让视野内的对手将当前装备的武器掉落在脚下，可重新拾取；不再施加恐惧状态。
- 嬗变卷轴（`ScrollOfTransmutation`）

升级卷轴（`ScrollOfUpgrade`）仅作为开局地图物资生成：每张地图固定6张，分为三对，
各占一个不同格子。每对按实战区局部坐标 `(x,y) ↔ (11-x,11-y)` 中心对称，
双方到对应物品的最短步数一致；位置随机且可步行到达，避开出生格、墙壁、深渊和不可通行位置。
开局生成后不会随计时、快照或重连补货，拾取及使用沿用现有规则。
