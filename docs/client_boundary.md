# 客户端与私有服务端边界

该客户端是完整工程的独立公开副本。完整工程与服务端继续保存在另一个私有目录，客户端无须加载其中的文件。

## 本仓库包含

- `assets/`：原版图像、声音、字体、翻译、物品资料及公开连接配置。
- `scenes/`：主菜单、日志、设置、秘卷投稿、保留的地图编辑／投稿界面、对战大厅和对局表现。
- `scripts/pvp/client/`：快照展示、选装界面、战斗操作与动画。
- `scripts/pvp/net/`：客户端连接／重连、RPC声明、快照解码、公开阶段与地图坐标约定。
- `scripts/menu/`、`scripts/maps/`、`scripts/submissions/`：日志沙盒、用户设置、保留的地图编辑、秘卷150字校验、投稿请求与结果展示；不含投稿存储。
- 其他运行脚本及`shaders/`：渲染、背包、角色、弹道和预览所需共用规则。

## 本仓库不包含

- `scripts/pvp/server/`及`scenes/pvp/server.tscn`。
- `scripts/pvp/equipment_draft.gd`、`item_pricing.gd`、`arena_maps.gd`：服务端随机市场／售价计算和固定地图池生成。
- `scripts/maps/submission_store.gd`：投稿磁盘存储、列表管理和服务端读写实现。
- `scripts/pvp/server/scroll_submission_store.gd`：秘卷设计想法的服务端存储。
- `scripts/pvp/server/battle_history_store.gd`：全服最近100局战绩的持久化存储，客户端只保留公开摘要格式和只读查询入口。
- 服务端部署工具、服务文件、安装脚本、服务器管理指令及私有开发文档。
- `.godot/`缓存、测试日志、运行时投稿、发布安装包与签名密钥。

## 共用规则与协议

日志预览会在本机沙盒中计算命中、伤害、附魔、药剂、状态和环境效果，故这些规则实现保留在公开源码中。服务器的权威对局组织与持久化实现不随之公开。该拆分不承诺隐藏游戏规则或阻止他人根据客户端另行编写服务器。

客户端通过`PvpProtocol`读取公开阶段、坐标范围等约定，不再引用权威对局类。护甲刻印预览使用独立的`glyph_preview_world.gd`，只运行本地演示所需的护甲状态池计时。

`PvpNet`路径及全部`@rpc`方法的名称、声明与通道保持协议11兼容。服务端接收方法保留为空体；删除这些声明、改变RPC注解或节点路径可能造成Godot RPC校验失败。客户端不包含`host_server()`或匹配器。

`PUBLIC_FILES.sha256`记录整理完成时的公开源码清单，可检查副本完整性；日后正常编辑会改变对应哈希，不影响项目运行。GitHub提交前只选择本客户端目录，完整私有工程应位于另一个仓库。
