# 当前 PvP 物品价格

核对日期：2026-10-28。单位：金币。双方初始各500金币。当前选装池共117种；含初始深渊的裂隙／地心／夹层额外排除冲击波法杖后116种，价格规则不变。新增两种合剂尚未打包或部署。

数据由当前 PvpEquipmentDraft._pool()、InventoryCatalog／MissileRules.create() 和服务端 scripts/pvp/item_pricing.gd::value() 实际运行生成。下表为已鉴定、无诅咒物资的基础售价；市场武器／护甲有30%概率附带附魔／刻印，不额外加价。

近战、投掷、护甲、法杖和戒指：售价＝+0基础价×（等级+1），市场仅生成+0～+2，权重30:24:18。实战升级卷轴仍可将装备提升到+3及以上。投掷价格按表中固定整组数量计，不再乘数量。药剂、卷轴每项1～2份；种子、符石每项1～3份，均按实际份数计价。
